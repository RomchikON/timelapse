# 📷 24/7 Smart Timelapse Camera (Redmi Note 8 Pro + CLI)

Превращение смартфона Redmi Note 8 Pro (Android 11 / MIUI 12.5.8) в энергоэффективную автономную таймлапс-камеру с полным удаленным управлением по Wi-Fi через консоль ПК.

---

## ⚡ Особенности системы
- **Автономность и энергоэффективность:** Экран телефона выключен/заблокирован. Приложение работает как Foreground Service с типом `camera` и `WakeLock`. Потребление минимально, температура батареи ~27°C.
- **Разрешение и качество:** 720p (1280×720), битрейт ~3.5 Mbps, 30 fps, H.264.
- **Аппаратный энкодер:** Видео собирается силами чипа MediaTek Helio G90T (`MediaCodec` + `MediaMuxer` + OpenGL ES Surface) прямо на телефоне. Сборка видео занимает секунды.
- **Удаленное управление:** Все действия выполняются через консольную утилиту `tl` без необходимости трогать телефон.
- **Очистка памяти:** После успешной сборки MP4 все промежуточные кадры JPEG автоматически удаляются.

## 🚀 Быстрый старт на новом ПК

### 1. Требования на ПК
- Linux, macOS или Windows (WSL / PowerShell)
- Python 3
- `adb` (`android-tools` / Android SDK Platform-tools)

### 2. Подключение к телефону по Wi-Fi
Телефон уже настроен на постоянный ADB-порт `5555`:
```bash
adb connect 192.168.31.216:5555
adb devices
```
> **⚠️ Важное примечание по роутеру Xiaomi:**
> Роутер изолирует трафик между частотами 2.4 ГГц и 5 ГГц. ПК и телефон обязательно должны быть подключены к одной частоте (к 2.4 ГГц сети роутера `Romchik`).

### 3. Установка CLI утилиты `tl`
Скопируйте скрипт `cli/tl` в вашу директорию исполняемых файлов:
```bash
# Для Linux:
cp cli/tl ~/.local/bin/tl
chmod +x ~/.local/bin/tl

# Проверьте связь:
tl status
```

## 🛠 Команды консоли `tl`

| Команда | Описание |
|---|---|
| `tl status` | Выводит телеметрию: состояние, батарею, температуру, свободное место, число снятых кадров. |
| `tl preview` | Делает мгновенный свежий снимок с заблокированного телефона и открывает его на экране ПК. |
| `tl start [интервал] [лимит_кадров]` | Запускает таймлапс (по умолчанию каждые 15 сек). Пример: `tl start 10 300` |
| `tl stop` | Останавливает съемку и автоматически запускает сборку MP4 видео. |
| `tl schedule 09:00 21:00 [интервал]` | Задает расписание съемки по часам. |
| `tl videos` | Список всех готовых MP4 роликов на телефоне. |
| `tl pull [файл]` | Скачивает видео с телефона на ПК в папку `~/Videos/Timelapse/`. |
| `tl encode [session_id]` | Запускает ручную пересборку кадров в MP4. |
| `tl logs` | Выводит живой лог работы приложения с телефона. |
